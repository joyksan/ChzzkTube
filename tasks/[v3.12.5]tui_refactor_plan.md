# [v3.12.5] TUI 인터랙티브 개편 및 렌더링 최적화 계획 (SPEC-2026-UI-002 v2.0)

## 1. 개요 및 목적
Windows/PySide6 환경에서 발생하는 폰트 왜곡 및 렌더링 결함(ClearType 서브픽셀 번짐, 글리프 세로선 틈새)을 원천 차단하고, 콘솔 뷰어의 UX를 현대적인 "Frameless Minimalist Console & Sleek Dash & Head Indicator" 스타일로 개편합니다.

## 2. 화면 상태(State)별 디자인 명세

### 2.1 State 1: 첫 실행 (의존성 수급 단계)
* **상태 태그:** `FAIL` 대신 `FETCH`(`#00D8B4`), `QUEUE`(`#707070`) 적용
* **인풋 필드:** 딤(Dim) 처리하여 입력 잠금을 직관적으로 안내하며, 플레이스홀더에 `> Initializing portable runtime environment... (ESC Cancel)` 표출
* **고정 4행 인플레이스 갱신:** `yt-dlp`, `ffmpeg`, `node`, `bgutil` 4대 컴포넌트가 제자리에서 게이지 갱신

### 2.2 State 2: 일반 실행 (의존성 완료 후 기본 화면)
* **노이즈 격리:** 10줄의 헬스체크 및 절대 경로(`AppData\Local\...`)를 F12 상세 로그로 격리
* **원라이너 성공 뱃지:** 단 1줄의 성공 뱃지로 압축
  `✔ Environment ready  (ytdlp 2026.08 · ffmpeg 7.1 · node v22 · pot active)`
* **상단 핫키 내비게이션 바:** 대괄호·파이프 제거, 미들 닷(`·`) 분할, 투톤 스타일 적용
  - 키 심볼 (`F1`, `F2` 등): `#E5E5E5`
  - 액션 텍스트 (`Change`, `Open` 등): `#8A8A8A`
* **하단 인풋 액션 바:** `F4 Load .txt · ESC Clear · ↵ Start`

### 2.3 State 3: 작업 다운로드 진행 중 (Active Task)
* **파이프 절제 및 여백 정렬:** 세로선(`│`)을 없애고 여백 기반 컬럼 정렬
  `[19:45:10] DOWN  video_1080p   ━━━━━━━━━━━━╸┈┈┈   75% · 12.4 MB/s · ETA 00:32`
  `[19:45:12] MERGE audio_track   ━━━━╸┈┈┈┈┈┈┈┈┈┈┈   25% · muxing...`
* **인풋 프롬프트 상태 액션:** `[ESC] Abort · [F12] Detailed Log`

## 3. UI 컴포넌트 세부 규격 및 렌더링 전략

### 3.1 상태 태그 색상 팔레트
* `FETCH`: `#00D8B4` (민트/시안)
* `QUEUE`: `#707070` (딤드 그레이)
* `✔` / `OK`: `#00D8B4` (민트)
* `ERR`: `#FF5555` (소프트 레드)

### 3.2 Sleek Dash & Head 프로그레스 바 글리프 사양
* **Filled Track (`━`, U+2501):** `#E5E5E5` (볼드 수평선)
* **Indicator Head (`╸`, U+2578):** `#00D8B4` (끝단 민트 화살머리)
* **Empty Track (`┈`, U+2508):** `#383838` (미세 점선 트랙)
* **너비:** 16칸 고정폭 정렬

### 3.3 폰트 엔진 및 위젯 렌더링 보정 (Windows)
* `QApplication.setHighDpiScaleFactorRoundingPolicy(PassThrough)`: 125%/150% DPI 오차 방지
* `QFont`: `Cascadia Mono`, `PreferNoHinting` (그리드 스냅 해제), `NoSubpixelAntialias | PreferAntialias` (ClearType 줄무늬 제거), `Weight.Medium` (Stem Darkening), `AbsoluteSpacing` 0.0 (글리프 밀착)
* `QTextEdit`: `setLineWrapMode(NoWrap)`, `WA_OpaquePaintEvent` 설정

## 4. 검증 체크리스트 (QA)
* 0%, 50%, 100% 진행 상황에서도 프로그레스 바 전체 문자 폭이 16칸으로 고정되는가?
* 일반 실행 시 콘솔에 10줄의 헬스체크 대신 `✔ Environment ready` 1줄 뱃지만 남는가?
* `qt-pilot` MCP 도구(위젯 트리, 캡처, 타이핑, 클릭)를 통해 E2E 작동이 정상 검증되는가?
